# descompressão memória ram | Compressão de memória do Windows desativada, para evitar o trabalho extra da CPU de comprimir e descomprimir dados.

DESATIVAR COMPRESSÃO DE MEMÓRIA

🔧1. Como aplicar

  • Prompt Abrir o PowerShell como Administrador
  • Comando Copiar e colar o código abaixo
  • Código Disable-MMAgent -MemoryCompression
  • Execução Pressione Enter
  • Sistema Reinicie o computador após aplicar para ativar as alterações

🔎2. Como verificar

  • Código Get-MMAgent
  • Resultado A linha MemoryCompression deve mostrar False

↩️3. Como reverter

  • Código Enable-MMAgent -MemoryCompression
  • Sistema Reinicie o computador
O que isso faz:
• Desativa o recurso do Windows que comprime blocos de dados dentro da memória RAM para economizar espaço físico (útil em computadores com pouca memória).
• Evita o processamento extra da CPU para comprimir e descomprimir dados em tempo real. No meu setup, com bastante RAM, deixo desativado e noto menos micro-travamentos nos jogos.
• Faz mais sentido em PCs com bastante RAM (por exemplo, 16 GB ou 32 GB ou mais); em PCs com pouca memória, o recurso pode ser útil.
