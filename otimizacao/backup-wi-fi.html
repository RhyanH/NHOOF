# backup wi-fi | Métrica de interface para usar o cabo como principal e o Wi-Fi como backup.

CONFIGURAR BACKUP WI-FI (MÉTRICA DE INTERFACE)

🔌 1. Configuração do Cabo (Prioridade Máxima)

  • Win + R ncpa.cpl
  • Intel(R) Ethernet Controller I225-V Propriedades
  • Protocolo IP Versão 4 (TCP/IPv4) Propriedades
  • Avançado Na aba Geral
  • Desmarque Métrica automática
  • Métrica da interface 10
  • Janelas OK → OK → Fechar

📶 2. Configuração do Wi-Fi (Redundância/Backup)

  • Win + R ncpa.cpl
  • RZ616 Wi-Fi 6E 160MHz Propriedades
  • Protocolo IP Versão 4 (TCP/IPv4) Propriedades
  • Avançado Na aba Geral
  • Desmarque Métrica automática
  • Métrica da interface 50
  • Janelas Clique em OK → OK → Fechar
O que faz: Quanto menor a métrica, maior a prioridade. Com o cabo em 10 e o Wi-Fi em 50, o Windows usa o cabo e só passa para o Wi-Fi se o cabo cair.
