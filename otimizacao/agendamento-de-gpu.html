# agendamento de gpu | Agendamento de GPU acelerado por hardware (HAGS) para reduzir a latência.

AGENDAMENTO DE GPU (HAGS)

🖥️ 1. Configuração

  • Caminho Sistema → Tela → Elementos gráficos → Configurações gráficas avançadas
  • Agendamento de GPU acelerado por hardware Ativado
O que faz: Permite que a própria placa de vídeo gerencie sua memória diretamente, em vez de depender do processador, reduzindo a latência do sistema e melhorando a estabilidade do FPS nos jogos.
