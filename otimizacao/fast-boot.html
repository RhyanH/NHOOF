# fast boot | Desativação da inicialização rápida para garantir um boot limpo e sem bugs

Fast Boot

⚡ Fast Boot

  • Caminho Advanced Mode (F2) → Boot
  • Fast Boot Disabled
Por que desativar: Mantém a inicialização estável e evita bugs de drivers e conflitos de periféricos. Além disso, garante o acesso normal à BIOS ao pressionar as teclas durante o arranque, sem saltar o ecrã de POST.
