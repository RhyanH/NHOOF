# secure boot e tpm | Configurações de segurança obrigatórias para o Windows 11

Secure Boot e TPM

🔒 Secure Boot

  • Caminho Advanced Mode (F2) → Boot → Secure Boot
  • Secure Boot Enabled
  • Secure Boot Mode Standard
Por que ativar: Exigência obrigatória da Microsoft para a instalação do Windows 11. Também, é exigido por anti-cheat de kernel (Valorant, CS2 e Call of Duty) para permitir que os jogos abram sem erros

🛡️ TPM

  • Caminho Advanced Mode (F2) → Settings → Miscellaneous
  • Trusted Platform Module Enable ASP fTPM
Justificativa: Tira a responsabilidade de guardar dados sensíveis do sistema operacional e passa para um nível seguro de hardware. É a chave de segurança exigida pelo Windows 11 para manter o sistema limpo, estável e livre de bloqueios de compatibilidade
🔍

Como verificar se funcionou:
• Pressione Win + R → digite tpm.msc
• O campo Status deve exibir a mensagem: "O TPM está pronto para uso"
