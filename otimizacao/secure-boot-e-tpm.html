# secure boot e tpm | Configurações de segurança recomendadas para o Windows 11

Secure Boot e TPM

🔒Secure Boot

  • Caminho Advanced Mode (F2) → Boot → Secure Boot
  • Secure Boot Enabled
  • Secure Boot Mode Standard
Por que ativar: O Windows 11 exige um PC compatível com Secure Boot (e TPM 2.0), e deixar o Secure Boot ligado é o recomendado. Também é checado por anti-cheats de alguns jogos, como o Vanguard (Valorant), o Call of Duty Black Ops 7 e as partidas do FACEIT, que podem não abrir se ele estiver desligado.

🛡️TPM

  • Caminho Advanced Mode (F2) → Settings → Miscellaneous
  • Trusted Platform Module Enable ASP fTPM
Justificativa: O TPM é um chip de segurança (aqui, o fTPM da própria AMD, embutido no processador) que guarda chaves e dados sensíveis fora do sistema operacional. O Windows 11 exige o TPM 2.0, e recursos como BitLocker e Windows Hello dependem dele.
🔍

Como verificar se funcionou:
• Pressione Win + R → digite tpm.msc
• O campo Status deve exibir a mensagem: "O TPM está pronto para uso"
• Para conferir o Secure Boot: Win + R → digite msinfo32 → "Estado da Inicialização Segura" deve estar "Ativado"
