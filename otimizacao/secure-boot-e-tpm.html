🔒 Secure Boot

  • Caminho Advanced Mode (F2) → Boot → Secure Boot
  • Secure Boot Enabled (Active)
  • Modo Secure Boot Standard
O que faz: Serve para garantir que o PC só inicie com arquivos e programas confiáveis. Ele impede que vírus pesados e maliciosos infectem a inicialização do Windows antes mesmo do sistema ligar.

🛡️ TPM

  • Caminho Advanced Mode (F2) → Settings → Miscellaneous → Trusted Platform Module
  • AMD CPU fTPM Enable ASP fTPM
O que faz: É um chip de segurança (integrado no processador) que guarda senhas e chaves de criptografia. O Windows 11 exige isso obrigatoriamente, além de ser necessário para rodar vários jogos e programas atuais sem dor de cabeça.
