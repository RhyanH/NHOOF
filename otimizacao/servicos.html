# serviços | Serviços do Windows desativados para reduzir telemetria e processos em segundo plano.

SERVIÇOS (LOCAL)

🔧1. Como aplicar em cada serviço abaixo

  • Executar (Win + R) services.msc
  • Ação Dar dois cliques sobre o serviço → Alterar "Tipo de inicialização" para Desativado → Clicar no botão Parar

🛑2. Lista de serviços a desativar

  • Cartão inteligente Desativado → Parar
  • Microsoft Edge Update Service (edgeupdate / edgeupdatem) Desativado → Parar
  • Experiências do Usuário Conectado e Telemetria Desativado → Parar
  • GIGABYTE Update Service Desativado → Parar (só existe em PCs com o software da Gigabyte instalado; se não aparecer na lista, pule)
  • Registro remoto Desativado → Parar
  • Salvar Jogos no Xbox Live Desativado → Parar
  • Serviço Auxiliar de Compatibilidade de Programas Desativado → Parar (Pular se joga FiveM)
  • Serviço de Biometria do Windows Desativado → Parar
  • Serviço de Compartilhamento de Rede do Windows Media Player Desativado → Parar
  • Serviço de Experiência em Idiomas Desativado → Parar
  • Serviço de Geolocalização Desativado → Parar
  • Serviço de Rede Xbox Live Desativado → Parar
  • Serviço de Relatórios de Erro do Windows Desativado → Parar
  • Serviço do Participante do Programa Windows Insider Desativado → Parar
  • Spooler de Impressão Desativado → Parar
  • SysMain Desativado → Parar
  • Telefonia Desativado → Parar
  • Windows Search Desativado → Parar

⚠️3. Efeitos colaterais dos principais

  • Windows Search a pesquisa do menu Iniciar e do Explorador de Arquivos fica lenta ou limitada, porque os arquivos deixam de ser indexados.
  • Spooler de Impressão sem impressão (nem para PDF de impressora virtual que dependa dele). Religue se for imprimir.
  • Serviço de Biometria do Windows o Windows Hello (digital e reconhecimento facial) deixa de funcionar.
  • Salvar Jogos no Xbox Live e Serviço de Rede Xbox Live afetam o Xbox App e o Game Pass (salvamento de jogos na nuvem, party e chat de voz do Xbox). Pule os dois se usa esses recursos.
  • Serviço de Geolocalização aplicativos que usam sua localização (mapas, clima) deixam de receber a posição automática.
  • Microsoft Edge Update Service o Edge deixa de se atualizar sozinho; atualize manualmente de vez em quando para receber correções de segurança.
  • Cartão inteligente leitores de cartão (por exemplo, certificado digital em cartão) deixam de funcionar.

↩️4. Como reverter

  • Executar (Win + R) services.msc
  • Ação Dar dois cliques sobre o serviço → Alterar "Tipo de inicialização" para Automático (ou Manual) → Clicar em Iniciar
O que faz:
• Desativa serviços de telemetria, relatórios de erro e atualização em segundo plano (Experiências do Usuário Conectado e Telemetria, Relatórios de Erro, Edge Update, GIGABYTE Update, Insider). Isso reduz processos e tráfego em segundo plano; o ganho de CPU é pequeno.
• Windows Search para a indexação de arquivos e SysMain para o pré-carregamento de aplicativos na memória. Em SSD NVMe o efeito costuma ser pequeno e varia de PC para PC.
• Desativar um serviço não remove o driver nem o recurso do Windows: só impede que ele inicie junto com o sistema. Recursos como impressão, cartão inteligente, biometria e telefonia deixam de funcionar enquanto o serviço estiver desativado.
