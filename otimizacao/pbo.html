# pbo | Liberação dos limites de energia para maior desempenho do processador.

PBO

⚡ PBO

  • Caminho Advanced Mode (F2) → Settings → AMD Overclocking → AMD Overclocking → Precision Boost Overdrive
  • Precision Boost Overdrive Advanced
  • PBO Limits Motherboard
O que faz: Libera os limites de energia padrão de fábrica, permitindo que a placa-mãe forneça mais corrente de forma segura para o processador alcançar e manter frequências mais altas sob carga.
