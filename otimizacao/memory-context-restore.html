# memory context restore | Reaproveita o treinamento da memória RAM para agilizar a inicialização.

Memory Context Restore

🔄Memory Context Restore

  • Caminho Advanced Mode (F2) → Tweaker → Advanced Memory Settings
  • Memory Context Restore Enabled
  • Power Down Enable Enabled
O que faz: Guarda o resultado do treinamento da memória RAM (o ajuste de timings e sinais que a placa-mãe faz ao ligar) para não refazê-lo toda vez que você liga o PC. O primeiro boot depois de ativar demora mais; nos seguintes, a inicialização costuma ficar alguns segundos mais rápida (o ganho varia). Se tiver tela azul, falha ao ligar ou problemas ao sair da suspensão, desative a opção.
