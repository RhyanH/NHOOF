# memory context restore | Redução drástica do tempo de boot salvando o contexto da RAM.

Memory Context Restore

🔄 Memory Context Restore

  • Caminho Advanced Mode (F2) → Tweaker → Advanced Memory Settings
  • Memory Context Restore Enabled
  • Power Down Enable Enabled
O que faz: Evita que a placa-mãe fique testando a memória RAM do zero toda vez que você liga o PC, reduzindo drasticamente o tempo de boot para o sistema iniciar muito mais rápido.
