# msi utility | MSI Utility V3 para ativar o modo MSI nos principais dispositivos e reduzir o input lag.

MSI UTILITY V3

🎮 1. Configurações da GPU (RTX 4070)

  • Caixa "msi" Ativado
  • Coluna "Limit" 2
  • Coluna "Interrupt Priority" High

🌐 2. Configurações de rede (Intel I225-V)

  • Caixa "msi" Ativado
  • Coluna "Limit" 5
  • Coluna "Interrupt Priority" Normal

💾 3. Configurações de armazenamento

  • Controlador Padrão NVM Express Caixa "msi" Ativado (Prioridade: Undefined)
  • Controlador AHCI SATA Padrão Caixa "msi" Desativado (Prioridade: Undefined)

✅ 4. Como salvar e aplicar

  • Botão Apply Clicar no canto superior direito para salvar
  • Sistema Reiniciar o computador para aplicar
O que faz: Altera a comunicação dos principais hardwares com o processador para o modo MSI (Message Signaled Interrupts), reorganizando a fila de tarefas do Windows para reduzir drasticamente o input lag do sistema e evitar microgaguejos de áudio ou vídeo.
⚠️

Nota importante:
Atualizações de driver da NVIDIA resetam as chaves da GPU no Windows. Sempre reabra o programa após atualizar o driver de vídeo para refazer a configuração.
