# disable paging executive | Mantém drivers e o código do núcleo do sistema na memória RAM, em vez de enviá-los ao arquivo de paginação. Última modificação: 30/10/2026 às 21:20

DESATIVAR PAGING EXECUTIVE

🔧1. Como aplicar

  • Prompt Abrir o PowerShell como Administrador
  • Comando Copiar e colar o código abaixo
  • Código Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" -Name "DisablePagingExecutive" -Value 1
  • Execução Pressione Enter
  • Sistema Reinicie o computador após aplicar para ativar as alterações

↩️2. Como reverter

  • Código Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" -Name "DisablePagingExecutive" -Value 0
  • Sistema Reinicie o computador
O que isso faz:
• Faz o Windows manter os drivers do sistema e o código executável do kernel (núcleo do sistema operacional) na memória RAM física, sem enviá-los ao arquivo de paginação (pagefile.sys) no SSD ou HD quando estão ociosos.
• Isso pode evitar a leitura desses dados do disco (falhas de página) quando o sistema precisa deles de volta. O benefício depende da carga e do quanto de RAM livre existe; no meu setup, deixo ativado.
• Usa um pouco mais de RAM física, por isso faz mais sentido em máquinas com bastante memória (por exemplo, 16 GB ou mais).
