# disable paging executive | Mantém o núcleo do sistema na memória RAM para respostas mais rápidas e menos microgaguejos.

DESATIVAR PAGING EXECUTIVE

🔧 1. Como aplicar

  • Prompt Abrir o PowerShell como Administrador
  • Comando Copiar e colar o código abaixo
  • Código Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" -Name "DisablePagingExecutive" -Value 1
  • Execução Pressione Enter
  • Sistema Reinicie o computador após aplicar para ativar as alterações
O que isso faz:
• Força o Windows a manter os drivers do sistema e o código executável do kernel (núcleo do sistema operacional) residentes diretamente na memória RAM física, impedindo que o sistema envie esses arquivos essenciais para o arquivo de paginação (pagefile.sys) no SSD ou HD quando estiverem ociosos.
• Elimina os atrasos de leitura e os chamados "page faults" (falhas de página), que ocorrem quando o Windows precisa resgatar uma rotina do sistema de volta do disco de armazenamento, resultando em respostas de sistema muito mais rápidas e sem gargalos de comunicação.
• Reduz de forma drástica os microgaguejos (stutterings) e oscilações de quadros durante a jogatina, garantindo que o sistema operacional responda com a velocidade de transferência bruta e imediata das memórias RAM (altamente recomendado para máquinas com 16GB ou mais de RAM).
