# bios profiles | Salvamento de perfis de configuração personalizados na placa-mãe.

BIOS Profiles

💾BIOS Profiles

  • Caminho Advanced Mode (F2) → Save & Exit → BIOS Profiles
Perfil 1: SAFE
• Secure Boot: Enabled
• fTPM: Enable ASP fTPM
• Fast Boot: Disabled
• EXPO Profile: EXPO 1 (High Bandwidth: Enable)
• Memory Context Restore & Power Down: Enabled
• Above 4G Decoding & Re-Size BAR: Enabled
• PBO: Advanced (Limits: Motherboard)
• Curve Optimizer: All Cores (Negative 25)
• Platform Thermal Limit: Manual (85°C)
• Integrated Graphics: Disabled
O que faz: Permite salvar as suas configurações personalizadas diretamente na memória da placa-mãe, facilitando a restauração rápida após um reset de CMOS ou carregamento de padrões de fábrica. Nota: Atualizações de BIOS limpam os perfis salvos, por isso é essencial recriá-los após atualizar a placa.
