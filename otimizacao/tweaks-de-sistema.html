# tweaks de sistema | Comandos de terminal e ajustes de registro que desativam recursos de rede e de sistema pouco usados e ajustam o agendador do Windows. O ganho varia de PC para PC. Última modificação: 30/10/2026 às 21:20

OTIMIZAÇÕES AVANÇADAS DE REDE E SISTEMA

⚠️Antes de aplicar

  • Aviso Crie um ponto de restauração (veja o canal Ponto de Restauração). Reversão de cada item no fim da página.

⌨️1. Passo 1: Comandos de terminal (PowerShell como Admin)

  • Armazenamento Reservado Set-WindowsReservedStorageState -State Disabled
  • Rastreamento de Uso de Dados (DusmSvc) sc.exe stop DusmSvc → sc.exe config DusmSvc start= disabled
  • Assistente de Compatibilidade (PcaSvc) sc.exe stop PcaSvc → sc.exe config PcaSvc start= disabled (Pular se joga FiveM)
  • Protocolo Teredo netsh interface teredo set state disabled (Pular se usa Party/Voice do Xbox App ou Game Pass)
  • Túneis IPv6 (ISATAP & 6to4) netsh int isatap set state disabled → netsh int ipv6 6to4 set state disabled

🧬2. Passo 2: Ajustes no registro

  • Priorização de Threads da CPU (Win32PrioritySeparation) HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\PriorityControl
  • Alterar (DWORD 32 bits) Win32PrioritySeparation = 26 (Hexadecimal) ou 38 (Decimal)
  • Atraso de ACK & Algoritmo de Nagle (TcpAckFrequency & TCPNoDelay) HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\{ID-DA-SUA-PLACA-DE-REDE}
  • Criar/Alterar (DWORD 32 bits) TcpAckFrequency = 1
  • Criar/Alterar (DWORD 32 bits) TCPNoDelay = 1
  • Nota Dentro da pasta Interfaces existem várias pastas com nome em código ({...}). Abra a que tiver o seu endereço de IP (campo IPAddress ou DhcpIPAddress) igual ao do seu computador: essa é a sua placa de rede ativa. O código é diferente em cada computador.
  • Otimização de Entrega (Windows Update em Segundo Plano) HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization
  • Criar/Alterar (DWORD 32 bits) DODownloadMode = 0

↩️3. Como reverter

  • Passo 1 (PowerShell como Admin) Comandos abaixo
  • Armazenamento Reservado Set-WindowsReservedStorageState -State Enabled
  • DusmSvc sc.exe config DusmSvc start= auto → sc.exe start DusmSvc
  • PcaSvc sc.exe config PcaSvc start= auto → sc.exe start PcaSvc
  • Teredo netsh interface teredo set state default
  • ISATAP e 6to4 netsh int isatap set state default → netsh int ipv6 6to4 set state default
  • Passo 2 (registro) Valores abaixo
  • Win32PrioritySeparation volte o valor para 2 (padrão do Windows)
  • TcpAckFrequency e TCPNoDelay apague os dois valores na pasta da sua placa de rede
  • DODownloadMode apague o valor
  • Final Reinicie o computador.
O que essas alterações no registro fazem:
• Priorização de Threads (Win32PrioritySeparation): 26 em hexadecimal (38 em decimal) configura o agendador do Windows com fatias de tempo curtas e variáveis e reforço de prioridade ao programa em primeiro plano. Não há teste que prove ganho de FPS; o efeito, quando existe, é pequeno.
• Atraso de ACK & Algoritmo de Nagle (TcpAckFrequency & TCPNoDelay): Ajustam como o Windows confirma e agrupa pacotes TCP. A maioria dos jogos online usa UDP, que não é afetado, e o efeito em jogos não é comprovado. Pode ajudar em aplicações TCP sensíveis a atraso; não espere ganho de ping.
• Otimização de Entrega (DODownloadMode = 0): Desativa o compartilhamento P2P da Otimização de Entrega do Windows Update (só HTTP). Os downloads continuam funcionando.
