# politicas de grupo | Políticas de Grupo Local para reduzir a telemetria, desativar recursos de nuvem e deixar as atualizações em modo manual.

POLÍTICAS DE GRUPO LOCAL

⚠️Antes de começar

  • Aviso O gpedit.msc existe no Windows 11 Pro, Enterprise e Education. No Windows 11 Home ele não existe (o Windows diz que não encontra o arquivo). No Home, use o programa gratuito Policy Plus ou grave os mesmos valores direto no registro. Crie um ponto de restauração antes (veja o canal Ponto de Restauração) e anote o que alterou, para poder desfazer.

🔧1. Acessando o editor

  • Executar (Win + R) gpedit.msc

📡2. Coleta de Dados e Compilações de Visualização

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Coleta de Dados e Compilações de Visualização
  • Ativar/desativar o controle do usuário sobre compilações do Insider Desativado
  • Permitir pipeline de dados comerciais Desativado
  • Permitir Processamento da Análise de Área de Trabalho Desativado
  • Permitir que o nome do dispositivo seja enviado nos dados de diagnóstico do Windows Desativado
  • Permitir Dados de Diagnóstico Desativado
  • Permitir Processamento de Conformidade da Atualização Desativado
  • Permitir Processamento de Nuvem WUFB Desativado

🧩3. Compatibilidade de Aplicativos

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Compatibilidade de Aplicativos
  • Desativar a Telemetria de Aplicativos Habilitado
  • Desativar o Mecanismo de Compatibilidade de Aplicativos Habilitado
  • Desativar o Auxiliar de Compatibilidade de Programa Habilitado (Pular se joga FiveM)
  • Desativar o Coletor de Inventário Habilitado
  • Desativar o Mecanismo de Compatibilidade de SwitchBack Habilitado
  • Desativar o Gravador de Passos Habilitado

☁️4. Conteúdo de Nuvem

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Conteúdo de Nuvem
  • Desativar o conteúdo otimizado em nuvem Habilitado
  • Desligue o conteúdo do estado da conta do consumidor na nuvem Habilitado
  • Não mostrar dicas do Windows Habilitado
  • Desativar as experiências do cliente da Microsoft Habilitado

🎙️5. Controle por Voz

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Controle por Voz
  • Permitir a Atualização Automática de Dados de Fala Desativado

🤖6. IA do Windows

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → IA do Windows
  • Desabilitar Click to Do Habilitado
  • Desabilitar a experiência de pesquisa agêntica de Configurações Habilitado
  • Obs. estes dois itens só aparecem em versões recentes do Windows 11 (24H2/25H2 com as últimas atualizações) e podem não ter efeito no Pro/Home.

📁7. Explorador de Arquivos

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Explorador de Arquivos
  • Mostrar arquivos com base na sua conta e na atividade do provedor de nuvem Habilitado

🔎8. Pesquisar

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Pesquisar
  • Definir as informações que são compartilhadas na pesquisa Habilitado
  • Tipo de informações Informações Anônimas

📲9. Instalação por Push

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Instalação por Push
  • Desativar o serviço Instalação por Push Habilitado

📍10. Local e Sensores → Localizador do Windows

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Local e Sensores → Localizador do Windows
  • Desativar fornecedor de local de Windows Habilitado

🧭11. Localizar Meu Dispositivo

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Localizar Meu Dispositivo
  • Ativar/desativar Localizar Meu Dispositivo Desativado

🛒12. Loja

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Loja
  • Desabilitar Download e Instalação Automáticos de Atualizações Habilitado
  • Obs. os aplicativos da Microsoft Store (inclusive Xbox App e jogos do Game Pass) deixam de atualizar sozinhos. Atualize-os manualmente pela própria Loja de vez em quando.

🌐13. Microsoft Edge

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Microsoft Edge
  • Permitir que o Microsoft Edge inicie e carregue a página Inicial... Habilitado
  • Configurar o pré-carregamento de guia Impedir o pré-carregamento de guia
  • Permitir a pré-inicialização do Microsoft Edge na inicialização do Windows... Habilitado
  • Configurar pré-inicialização Impedir a pré-inicialização
  • Edge atual as quatro políticas acima são do Edge antigo (EdgeHTML) e não afetam o Edge atual. Para desligar o "Aumento de velocidade na inicialização" (Startup Boost) e a execução em segundo plano do Edge atual, abra o PowerShell como Administrador e cole os comandos abaixo.
  • Criar a chave New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Force
  • StartupBoostEnabled New-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Name "StartupBoostEnabled" -PropertyType DWord -Value 0 -Force
  • BackgroundModeEnabled New-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Name "BackgroundModeEnabled" -PropertyType DWord -Value 0 -Force
  • Verificar Reinicie o Edge e abra edge://policy. As duas políticas devem aparecer com valor false. O Edge passa a mostrar "Gerenciado pela sua organização", o que é normal quando há política aplicada.
  • Reverter Remove-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Name "StartupBoostEnabled"; Remove-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Name "BackgroundModeEnabled"
  • Obs. estes comandos funcionam em qualquer edição do Windows (Home, Pro etc.).

🐞14. Relatórios de Erros do Windows

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Relatórios de Erros do Windows
  • Desabilitar Relatório de Erros do Windows Habilitado
  • Desabilitar log Habilitado

🧱15. Widgets

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Widgets
  • Desabilitar o Quadro de Widgets Habilitado

📦16. Otimização de Entrega

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Otimização de Entrega
  • Modo de Download Habilitado
  • Modo de Download Bypass (100)

🔄17. Windows Update → Gerenciar a Experiência do Usuário Final

  • Caminho Configuração do Computador → Modelos Administrativos → Componentes do Windows → Windows Update → Gerenciar a Experiência do Usuário Final
  • Configurar Atualizações Automáticas Habilitado
  • Configurar atualização automática 2 - Avisar antes de baixar e instalar automaticamente
  • Obs. nesse modo o Windows não baixa nada sozinho. Verifique as atualizações do Windows de vez em quando (sugestão: uma vez por mês) para instalar as correções de segurança.

🖥️18. Sistema → Políticas do SO

  • Caminho Configuração do Computador → Modelos Administrativos → Sistema → Políticas do SO
  • Habilita o Feed de Atividades Desativado

📶19. Rede → Agendador de Pacotes QoS

  • Caminho Configuração do Computador → Modelos Administrativos → Rede → Agendador de Pacotes QoS
  • Limitar largura de banda reservável Habilitado
  • Limite de largura de banda 0%
O que faz:
• Reduz a coleta de diagnóstico ao mínimo que o Windows permite. No Home/Pro o nível mais baixo ("Necessário") continua ativo; só Enterprise/Education chegam a "Desativado". Várias políticas da seção 2 só têm efeito em PCs gerenciados por empresa. O foco é privacidade e menos ruído, não ganho de FPS.
• Desliga recursos de nuvem, dicas, widgets, tarefas de compatibilidade de aplicativos, relatórios de erro e ferramentas de IA do Windows, reduzindo processos e envio de dados em segundo plano.
• Deixa as atualizações automáticas em modo manual (você decide quando baixar e instalar) e mexe no compartilhamento de atualizações entre computadores (P2P) da Otimização de Entrega.
• Limite de largura de banda 0%: a reserva padrão de 20% do QoS só é usada quando algum programa pede prioridade de rede; do contrário, o Windows já deixa a banda livre. Deixar em 0% é inofensivo, mas não aumenta a sua velocidade.
