# windows update | Evita o download automático de apps de fabricantes e reduz o uso da sua internet pela Otimização de Entrega. Última modificação: 30/10/2026 às 21:20

Windows Update

🚫Apps e Ícones de Fabricantes

  • Caminho Win + R → sysdm.cpl → Hardware → Configurações de Instalação do Dispositivo
  • Instalação automática Não
O que faz: Impede que o Windows baixe automaticamente aplicativos e ícones personalizados dos fabricantes dos seus dispositivos. Atenção: essa opção não impede o Windows Update de oferecer drivers; para isso, veja a dica extra abaixo.

📦Otimização de Entrega

  • Caminho Configurações → Windows Update → Opções Avançadas → Otimização de Entrega
  • Permitir downloads de outros PCs Desativado
O que faz: Evita que o seu PC use a sua internet para enviar partes de atualizações para outros computadores (e receber delas). Com a opção desativada, o PC baixa direto da Microsoft.
💡

Nota de transparência:
Ao escolher Não, o Windows mostra o aviso "seu dispositivo pode não funcionar como esperado". É só um alerta padrão da Microsoft: a opção apenas bloqueia o download automático de apps e ícones de fabricantes, e o seu dispositivo continua funcionando normalmente. Os drivers continuam chegando pelo Windows Update.

🛡️

Dica extra: bloquear drivers de verdade
Para impedir que o Windows Update inclua drivers nas atualizações, use um destes dois métodos:

Opção 1 (Política de Grupo, não existe no Windows Home): Win + R → gpedit.msc → Configuração do Computador → Modelos Administrativos → Componentes do Windows → Windows Update → Gerenciar atualizações oferecidas pelo Windows Update → Não incluir drivers com as atualizações do Windows → Habilitada.

Opção 2 (registro, PowerShell como Administrador):
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" -Force
New-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" -Name "ExcludeWUDriversInQualityUpdate" -Value 1 -PropertyType DWord -Force
Para desfazer: Remove-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" -Name "ExcludeWUDriversInQualityUpdate"

Com isso ativo, os drivers passam a ser instalados só por você (pelos sites dos fabricantes).
