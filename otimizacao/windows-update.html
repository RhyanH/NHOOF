# windows update | Configurações essenciais para evitar drivers genéricos e otimizar atualizações.

Windows Update

🚫 Bloquear Drivers

  • Caminho Win + R → sysdm.cpl → Hardware → Configurações de Instalação do Dispositivo
  • Instalação automática Não
O que faz: Impede que o Windows instale automaticamente drivers genéricos que possam causar instabilidade ou quedas de FPS.

📦 Otimização de Entrega

  • Caminho Configurações → Windows Update → Opções Avançadas → Otimização de Entrega
  • Permitir downloads de outros PCs Desativado
O que faz: Evita o uso oculto da sua largura de banda para transferir arquivos de atualização para computadores de terceiros.
💡

Nota de transparência:
O aviso da Microsoft "o dispositivo pode não funcionar" é apenas um alerta padrão.
