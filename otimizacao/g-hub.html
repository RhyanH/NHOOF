# g-hub | Configurações gerais, análise, perfis e equalização.

G HUB

⚙️ Configurações (Geral)

  • Iniciar o aplicativo no login ON
  • Desativar automaticamente a iluminação OFF
  • Controle de iluminação do jogo OFF
  • Notificações do sistema OFF
  • Recomendações OFF

📊 Configurações (Análise)

  • Compartilhar meus dados de uso OFF
  • Enviar logs de erros automaticamente quando o G HUB encontra problemas OFF
O que faz: Mantém o G HUB iniciando com o Windows e desliga o envio de dados de uso e de relatórios de erro, além do controle de iluminação por jogo, das notificações e das recomendações.

🎯 Gerenciar Perfil

  • Perfil de Jogos GadgetryTech FPS Comp
  • Perfil de Mídia BEST ALL-ROUND EQ (V3)
O que faz: Usa o perfil voltado para FPS nos jogos e o perfil equilibrado para mídia e uso geral (YouTube, filmes, séries, Spotify), alternando entre eles conforme o uso.

🎛️ Equalização (EQ)

  • Perfil Jogos A50X GadgetryTech FPS Comp (GadgetryTech)
  • Perfil Mídia/Geral BEST ALL-ROUND EQ (V3) (Knrauxx)
O que faz: Usa perfis de equalização criados pela comunidade para os drivers de grafeno do A50 X, um para jogos e outro para mídia.
