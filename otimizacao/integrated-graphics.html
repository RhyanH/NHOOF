# integrated graphics | Desativação do chip gráfico integrado para evitar conflitos de vídeo.

Integrated Graphics

🎮 Integrated Graphics

  • Caminho Advanced Mode (F2) → Settings → IO Ports
  • Integrated Graphics Disabled
O que faz: Desativa o processador gráfico embutido do processador, liberando recursos do sistema e evitando conflitos indesejados de drivers de vídeo.
⚠️

Aviso importante: Só desative esta opção caso você utilize uma placa de vídeo dedicada. Caso contrário, você perderá o sinal de vídeo ao iniciar o computador.
