# hibernação | Desativação da hibernação para liberar espaço no SSD e otimizar o sistema.

HIBERNAÇÃO

💤 1. Desativar Hibernação

  • Terminal PowerShell / CMD (Admin)
  • Comando powercfg /hibernate off
O que faz: Desativa a hibernação do Windows.

Verificar se deu certo: Cole o comando powercfg /a no terminal. Se aparecer a mensagem "A hibernação não foi habilitada", deu certo!
