# cursor | Pacote de cursores Windows 11 Concept para trocar o visual do mouse.

CURSOR

🖱️1. Pacote de cursores

  • Windows 11 Cursors Concept v2 Abrir página de download

⚠️2. Antes de instalar

  • Aviso É um pacote de terceiros. Baixe somente pela página indicada acima e passe o antivírus antes de abrir. É uma mudança só visual.

🛠️3. Como instalar

  • 1Extraia o arquivo baixado
  • 2Clique com o botão direito no arquivo .inf e escolha Instalar
  • 3Depois, nas opções de ponteiros do mouse do Windows, escolha o esquema do pacote instalado e aplique

↩️4. Como voltar ao padrão

  • Padrão Nas mesmas opções de ponteiros, escolha de novo o esquema padrão do Windows e aplique
