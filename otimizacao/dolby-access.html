# dolby access | Dolby Atmos for Headphones com o Modo de Desempenho do Dolby Access para áudio posicional.

DOLBY ACCESS

🎧1. Propriedades de Fones de Ouvido (Som Espacial)

  • Dispositivo Astro A50X Game
  • Áudio Espacial Dolby Atmos for Headphones

🎮2. Configuração no aplicativo Dolby Access

  • Jogos → Modo de Desempenho Ativado
O que faz: Ativa o áudio espacial (surround virtualizado) nos fones, o que ajuda a localizar de onde vêm os sons, como passos e disparos. O Modo de Desempenho é um ajuste do aplicativo Dolby Access para jogos.
💰

Observação: o Dolby Atmos for Headphones é pago no Windows (há um período de teste gratuito no aplicativo Dolby Access; depois é preciso comprar a licença).
