# platform thermal limit | Definição de um teto de temperatura personalizado para o processador. Última modificação: 30/10/2026 às 21:20

Platform Thermal Limit

🌡️Platform Thermal Limit

  • Caminho Advanced Mode (F2) → Settings → AMD Overclocking → AMD Overclocking → Precision Boost Overdrive
  • Platform Thermal Throttle Ctrl Manual
  • Platform Thermal Throttle Limit 85
O que faz: Define um teto de temperatura para o processador. Ao chegar em 85°C, ele reduz clock e tensão para não passar disso. É uma escolha minha para manter o processador mais frio, não uma proteção contra dano.
💡

Por que limitar em 85°C:
O limite oficial da AMD para o 9800X3D é 95°C. Usar 85°C deixa o processador 10°C abaixo disso, com mais margem de temperatura. Em cargas muito pesadas, pode custar um pouco de desempenho.
