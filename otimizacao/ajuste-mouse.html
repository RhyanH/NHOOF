# ajuste mouse | Desativação da aceleração do mouse do Windows para movimento 1:1.

AJUSTE DE MOUSE (ACELERAÇÃO DO WINDOWS)

🖱️ 1. Configuração

  • Aprimorar precisão do ponteiro Desativado (OFF)

🛠️ 2. Como fazer

  • Prompt Pressione Windows + R no teclado
  • Comando main.cpl
  • Aba Opções do Ponteiro
  • Aplicação Desmarque "Aprimorar precisão do ponteiro" → Aplicar → OK
O que faz:
• Desativa por completo o algoritmo de aceleração linear de movimento nativo do sistema operacional Windows (conhecido tecnicamente como curva de aceleração de pixel).
• Garante uma relação de rastreamento estrita de 1:1 entre o sensor físico do mouse e o cursor na tela. Sem esse recurso ativo, a distância que a sua mira percorre dentro de jogos competitivos (como o Valorant) passa a depender única e exclusivamente do espaço físico real que você deslocou o mouse sobre o mousepad, ignorando totalmente a velocidade mecânica do seu movimento.
• Elimina variações artificiais e imprevisíveis na sensibilidade do jogo, atuando como o pilar fundamental para o desenvolvimento de uma memória muscular consistente, flicks precisos e controle de spray refinado.
