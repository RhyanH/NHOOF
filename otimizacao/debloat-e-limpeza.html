# debloat-e-limpeza | Uso de ferramentas avançadas para debloat, bloqueio de telemetria e limpeza profunda.

DEBLOAT E LIMPEZA

🧹 1. Revo Uninstaller

  • Download Free Portable
  • Abas de Uso Uninstaller / Windows Apps
  • Modo de Varredura Avançado (Advanced)
Como usar: Use a aba Uninstaller para programas comuns e Windows Apps para os nativos. Mantenha o ponto de restauração ativado, selecione o modo Avançado no escaneamento de sobras e apague os registos encontrados.

💡 Recomendação: Reinicie o PC para finalizar a remoção de ficheiros pendentes antes de avançar para o próximo passo.

🛠️ 2. Winutil (Chris Titus)

  • Terminal PowerShell (Admin)
  • Comando irm christitus.com/win | iex
  • Recomendação Aba "Tweaks" ➔ Desktop
O que faz: Utilitário definitivo em código aberto. Desinstala bloatwares, desativa widgets e aplica otimizações profundas no sistema com um único clique.

💡 Recomendação: Reinicie o PC após aplicar os ajustes para consolidar todas as alterações no Registro do Windows.

🕵️ 3. O&O ShutUp10++

  • Download O&O ShutUp10 Grátis
  • Instalação Portátil (Não requer)
  • Perfil de uso Apply only recommended settings
  • Manutenção Reaplicar após grandes updates do Win
O que faz: Bloqueia a telemetria invasiva do Windows, cortando o envio oculto de dados de uso para os servidores da Microsoft em segundo plano.

🧽 4. Limpeza do Sistema

  • Sensor de Armazenamento Ativado (Semanal)
  • Pasta Temp (Win+R) Limpar manualmente
  • Limpeza de Disco Limpar Arquivos do Sistema
O que faz: Elimina caches residuais, registos antigos do Windows Update e lixo de uso contínuo para desocupar espaço vital no SSD.
