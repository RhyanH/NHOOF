# regedit | Ajustes de registro aplicados por comando no PowerShell para reduzir latência e liberar o processador.

REGEDIT

🔧 1. Como aplicar

  • Prompt Abrir o PowerShell como Administrador
  • Execução Escolha o ajuste abaixo, copie o comando completo, cole no PowerShell e aperte Enter
  • Sistema Reinicie o computador após aplicar para ativar as alterações

⌨️ 2. Comandos (otimizações de registro)

  • Desativar Otimização de Entrega (DOSvc) Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\DOSvc" -Name "Start" -Value 4
  • Forçar Tela Inteira Nativa (FSE) Set-ItemProperty -Path "HKCU:\System\GameConfigStore" -Name "GameDVR_FSEBehavior" -Value 2
  • Desativar Throttling de Rede Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "NetworkThrottlingIndex" -Value 0xffffffff
  • Responsividade Máxima do Sistema Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "SystemResponsiveness" -Value 0
  • Desativar Power Throttling da CPU Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Power" -Name "PowerThrottlingOff" -Value 1
O que faz:
• DOSvc (Value 4): Desativa o serviço de Otimização de Entrega do Windows Update, impedindo que o sistema use sua conexão em segundo plano para enviar trechos de atualizações para outros computadores na internet (P2P), poupando banda e processamento.
• GameDVR_FSEBehavior (Value 2): Altera o comportamento do sistema para mitigar os problemas das Otimizações de Tela Inteira híbridas do Windows, facilitando o acionamento do modo Tela Inteira Exclusiva real nos jogos para reduzir o input lag e bugs de taxa de atualização.
• NetworkThrottlingIndex (Value 0xffffffff): Desliga por completo o mecanismo nativo do Windows que limita a velocidade de transferência de pacotes de rede não multimídia quando há processamento pesado em execução, garantindo a menor latência (ping) possível e eliminando perdas de pacotes.
• SystemResponsiveness (Value 0): Remove a reserva padrão do sistema que retém 20% dos recursos do processador para serviços secundários em segundo plano, liberando 100% da capacidade de processamento da CPU para priorizar o jogo que estiver aberto no momento.
• PowerThrottlingOff (Value 1): Desativa globalmente o estrangulamento energético de processos do Windows, impedindo que o sistema operacional reduza de forma artificial a frequência ou jogue threads ativas da CPU para estados de economia de energia, eliminando microgaguejos (stutterings).
