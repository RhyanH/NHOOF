# regedit | Ajustes de registro aplicados por comando no PowerShell. O efeito varia de PC para PC e em vários casos é pequeno. Última modificação: 30/10/2026 às 21:20

REGEDIT

⚠️Antes de aplicar

  • Aviso Crie um ponto de restauração (veja o canal Ponto de Restauração). Mexer no registro errado pode quebrar o Windows. No fim da página estão os comandos para voltar aos valores padrão.

🔧1. Como aplicar

  • Prompt Abrir o PowerShell como Administrador
  • Execução Escolha o ajuste abaixo, copie o comando completo, cole no PowerShell e aperte Enter
  • Sistema Reinicie o computador após aplicar para ativar as alterações

⌨️2. Comandos (otimizações de registro)

  • Desativar Otimização de Entrega (DOSvc) Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\DOSvc" -Name "Start" -Value 4
  • Forçar Tela Inteira Nativa (FSE) Set-ItemProperty -Path "HKCU:\System\GameConfigStore" -Name "GameDVR_FSEBehavior" -Value 2
  • Desativar Throttling de Rede (multimídia) Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "NetworkThrottlingIndex" -Value 0xffffffff
  • Reservar menos CPU para tarefas de segundo plano Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "SystemResponsiveness" -Value 10
  • Desativar Power Throttling da CPU New-Item -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Power\PowerThrottling" -Force
    New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Power\PowerThrottling" -Name "PowerThrottlingOff" -PropertyType DWord -Value 1 -Force

↩️3. Como voltar ao padrão

  • Passos Mesmos passos (PowerShell como Administrador, depois reiniciar)
  • DOSvc Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\DOSvc" -Name "Start" -Value 3
  • GameDVR_FSEBehavior Set-ItemProperty -Path "HKCU:\System\GameConfigStore" -Name "GameDVR_FSEBehavior" -Value 0
  • NetworkThrottlingIndex Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "NetworkThrottlingIndex" -Value 10
  • SystemResponsiveness Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" -Name "SystemResponsiveness" -Value 20
  • PowerThrottlingOff Remove-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Power\PowerThrottling" -Name "PowerThrottlingOff"
O que faz:
• DOSvc (Value 4): Desativa o serviço de Otimização de Entrega do Windows, impedindo que o sistema use sua conexão em segundo plano para enviar trechos de atualizações para outros computadores (P2P), poupando banda e processamento.
• GameDVR_FSEBehavior (Value 2): Altera o comportamento das Otimizações de Tela Inteira do Windows, com a intenção de os jogos usarem tela inteira exclusiva real. Pode ajudar em jogos com problema de taxa de atualização; não há medição pública de menos input lag, e o efeito depende do jogo.
• NetworkThrottlingIndex (Value 0xffffffff): Desliga o limite de pacotes de rede por milissegundo que o Windows aplica quando há reprodução de mídia (multimídia) em andamento. Só atua nesse cenário; não reduz ping nem elimina perda de pacotes em jogos.
• SystemResponsiveness (Value 10): Define a parcela de CPU garantida a tarefas de baixa prioridade quando há programas multimídia/jogos rodando pelo agendador multimídia do Windows (MMCSS). O padrão é 20%; 10% é o menor valor com efeito (a Microsoft trata valores abaixo de 10 como 20). Não libera 100% da CPU.
• PowerThrottling (PowerThrottlingOff = 1): Desliga o Power Throttling, a economia de energia que o Windows aplica a processos em segundo plano. Foi pensado para notebooks na bateria; em desktop o efeito é pequeno.
