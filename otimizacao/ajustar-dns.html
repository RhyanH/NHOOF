# ajustar dns | DNS da Cloudflare configurado no adaptador de rede para reduzir a latência de rota.

AJUSTAR DNS (LATÊNCIA DE ROTA)

⚙️ 1. Configuração

  • Win + R ncpa.cpl
  • Intel(R) Ethernet Controller I225-V Propriedades
  • Protocolo IP Versão 4 (TCP/IPv4) Propriedades
  • Selecione Usar os seguintes endereços de servidor DNS
  • Servidor preferencial 1.1.1.1
  • Servidor alternativo 1.0.0.1

💾 2. Para salvar e ativar

  • Janelas OK → Fechar
  • Prompt de Comando (CMD) ipconfig /flushdns

🔎 3. Como testar

  • Prompt de Comando (CMD) ping 1.1.1.1
  • Verifique a linha final O resultado ideal deve apresentar 0% de perda e a menor Média em ms possível para a sua região

✅ 4. Como verificar se funcionou após aplicar

  • Prompt de Comando (CMD) nslookup google.com 1.1.1.1
  • Resultado Se nas primeiras linhas aparecer Server: one.one.one.one e Address: 1.1.1.1, o Windows já está navegando e jogando com a rota otimizada da Cloudflare
