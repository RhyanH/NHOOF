# ajustar dns | DNS da Cloudflare configurado no adaptador de rede para resolver os nomes de sites e serviços.

AJUSTAR DNS (CLOUDFLARE)

⚙️1. Configuração

  • Win + R ncpa.cpl
  • Intel(R) Ethernet Controller I225-V Propriedades
  • Protocolo IP Versão 4 (TCP/IPv4) Propriedades
  • Selecione Usar os seguintes endereços de servidor DNS
  • Servidor preferencial 1.1.1.1
  • Servidor alternativo 1.0.0.1

💾2. Para salvar e ativar

  • Janelas OK → Fechar
  • Prompt de Comando (CMD) ipconfig /flushdns

🔎3. Teste de conexão

  • Prompt de Comando (CMD) ping 1.1.1.1
  • Verifique a linha final O resultado ideal deve apresentar 0% de perda e a menor Média em ms possível para a sua região. Esse teste mede a conexão até a Cloudflare, não o DNS.

✅4. Como verificar se funcionou após aplicar

  • Prompt de Comando (CMD) nslookup google.com
  • Resultado Se nas primeiras linhas aparecer Server: one.one.one.one e Address: 1.1.1.1, o Windows está usando o DNS da Cloudflare
O que faz: O DNS traduz o nome de um site ou serviço (como google.com) no endereço numérico dele. Aqui o Windows passa a fazer essa consulta pelos servidores da Cloudflare. O DNS não muda a rota nem o ping dos jogos.
↩️

Como voltar atrás:
Na mesma janela do TCP/IPv4, volte a configuração do DNS para o modo automático e clique em OK.
